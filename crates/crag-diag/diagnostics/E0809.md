---
code: E0809
name: ParamNotStorable
title: A type argument that is not `Storable`
spec: 21.5
---

A type parameter required `is Storable` takes only `Storable` types: the
type is `Solid`, is not `Secret`, and every opaque type in it declares
an `Encode`/`Decode` pair (§18.9). A plain closure is compiled code and
never storable; of function values, only `Expr` values are (§21.5). The
message names the part that fails.

## Rationale

A stored value outlives the process, so everything in it must encode to
bytes and decode back. A runtime handle or a compiled closure is bound
to its process, and a `Secret` must not reach a file.

## Failing

```crag
opaque type Token(raw: Int)

fn keep[T](x: T) -> T where T is { Storable } { x }

fn f() -> Int {
  let t = keep(Token(raw: 1))
  1
}
```

## Fixed

```crag
distinct type Token(raw: Int)

fn keep[T](x: T) -> T where T is { Storable } { x }

fn f() -> Int {
  let t = keep(Token(raw: 1))
  1
}
```
