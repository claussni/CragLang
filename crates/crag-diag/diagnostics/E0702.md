---
code: E0702
name: ExprNotPure
title: `Expr` of a function type that is not `is Pure`
spec: 18.6
---

`Expr[F]` is code that can be sent to another node, and its `F` must be
an `is Pure` function type. Writing `Expr` of a plain function type,
which may perform effects, is an error at the type.

## Rationale

Transported code runs on a receiver and must perform no I/O there.
Mark the function type Pure, as in `Expr[((Int) -> Int is Pure)]`; the
parentheses keep `is Pure` on the function type.

## Failing

```crag
import std.transport

fn send(job: Expr[(Int) -> Int]) -> Int { job(1) }
```

## Fixed

```crag
import std.transport

fn send(job: Expr[((Int) -> Int is Pure)]) -> Int { job(1) }
```
