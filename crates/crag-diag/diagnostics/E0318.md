---
code: E0318
name: NotDiscrete
title: A range of a type that is not Discrete
spec: 7.4
---

Both ends of a range `a..b` must have a type that fits `Discrete`,
which gives the next value after each. `Int`, the sized integers,
`CodePoint` and `Fixed[S]` fit it. `Float` and types without a `next`
form no range, in an expression or in a pattern.

## Rationale

A float has no next value, since the gap between neighbours depends on
the magnitude. Compare with `<` and `<=` instead, or use a `Fixed[S]`
value, whose ranges step by its smallest digit.

## Failing

```crag
fn grade(score: Float) -> Str {
  case score {
    0.0..0.5 -> "fail"
    _ -> "pass"
  }
}
```

## Fixed

```crag
fn grade(score: Float) -> Str {
  if score < 0.5 { "fail" } else { "pass" }
}
```
