---
code: E0517
name: NotAMarker
title: A requirement `T is X` of something that is not a type marker
spec: 4.2
---

`T is X` in a `where` clause requires a marker that describes types:
`Solid`, `Pure`, `Secret`, `Storable`, `Immediate` or `Deferred`. A form,
a named type or a marker of foreign libraries such as `ThreadSafe` is
refused there.

## Rationale

The other markers describe foreign libraries and functions, not types,
and a form is required with its own syntax. Write a form as a bound,
`[T: Sized]` or `where Sized[T]`.

## Failing

```crag
form Sized[T] {
  size(x: T) -> Int
}
fn cache[T](x: T) -> T where T is Sized { x }
```

## Fixed

```crag
form Sized[T] {
  size(x: T) -> Int
}
fn cache[T: Sized](x: T) -> T { x }
```
