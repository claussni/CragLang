---
code: E0608
name: ValueNotSolid
title: A module-level binding that is not Solid
spec: 5.5
---

A module-level `let` or `embed` holds only Solid values. The value is
computed at compile time or once on first use and is shared by the
whole program. A function that is not `is Pure` and a `lazy` value are
not Solid.

## Rationale

A module-level value must never fail or act when it is read. Mark a
function value `is Pure`, or move the binding into the function that
uses it.

## Failing

```crag
let increment: (Int) -> Int = { n -> n + 1 }
```

## Fixed

```crag
let increment: ((Int) -> Int is Pure) = { n -> n + 1 }
```
