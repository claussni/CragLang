---
code: E0705
name: OuterFunction
title: Code sent as an `Expr` that calls a local function from outside it
spec: 18.6
---

A closure literal that becomes an `Expr` may not call a local function
declared outside the closure. The `Expr` tree bundles module-level
helpers, but not local functions yet.

## Rationale

A local function is code, not a value, and the tree has no way to carry
it for now. Move the function to module level, where the `Expr` can
reference or bundle it, or declare it inside the closure.

## Failing

```crag
import std.transport

fn send(job: Expr[((Int) -> Int is Pure)]) -> Int { job(1) }

fn total() -> Int {
  fn inc(n: Int) -> Int { n + 1 }
  send({ n -> inc(n) })
}
```

## Fixed

```crag
import std.transport

fn send(job: Expr[((Int) -> Int is Pure)]) -> Int { job(1) }

fn inc(n: Int) -> Int { n + 1 }

fn total() -> Int {
  send({ n -> inc(n) })
}
```
