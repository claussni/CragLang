---
code: E0203
name: NotInEveryAlternative
title: An or-pattern alternative that does not bind every name
spec: 6.9
---

A pattern `A | B` matches when any alternative does. Every name it
binds must be bound by each alternative, because the arm's body runs
whichever one matched. A name bound by only some alternatives is an
error.

## Rationale

Otherwise the body could read a binding that has no value. Bind the
name in every alternative, or split the alternatives into separate
arms.

## Failing

```crag
type Circle(radius: Int)
type Square(side: Int)

fn size(shape: Circle | Square) -> Int {
  case shape {
    Circle(radius: n) | Square(side: _) -> n
  }
}
```

## Fixed

```crag
type Circle(radius: Int)
type Square(side: Int)

fn size(shape: Circle | Square) -> Int {
  case shape {
    Circle(radius: n) | Square(side: n) -> n
  }
}
```
