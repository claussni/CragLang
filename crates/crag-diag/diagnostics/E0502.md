---
code: E0502
name: FormMissing
title: A form whose function no visible function provides
spec: 4.6
---

A type fits a form when a function of each of the form's signatures is
visible where the call that fixes the type argument is written. When one
is missing, the bound does not hold. The message names the form, the
function and the type it must have.

## Rationale

Fitting is structural: nothing is declared on the type, so the only way
to fit is to have the functions. Declare the missing function for the
type, or import the module that has it.

## Failing

```crag
form Sized[T] {
  size(x: T) -> Int
}
type Box(w: Int, h: Int)
fn biggest[T: Sized](a: T, b: T) -> T {
  if size(a) >= size(b) { a } else { b }
}
fn main() -> Box { biggest(Box(w: 1, h: 2), Box(w: 3, h: 1)) }
```

## Fixed

```crag
form Sized[T] {
  size(x: T) -> Int
}
type Box(w: Int, h: Int)
fn size(b: Box) -> Int { b.w * b.h }
fn biggest[T: Sized](a: T, b: T) -> T {
  if size(a) >= size(b) { a } else { b }
}
fn main() -> Box { biggest(Box(w: 1, h: 2), Box(w: 3, h: 1)) }
```
