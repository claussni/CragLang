---
code: E0602
name: PureCall
title: A function with effects passed to a Pure one
spec: 3.14
---

An `is Pure` function may call the functions it receives as
parameters. A call of it must then pass functions without effects, so
the call stays pure. The message names the Pure function.

## Rationale

The Pure function has no effects only if the functions it calls have
none. Pass a closure without effects, or call a function that is not
`is Pure`.

## Failing

```crag
import std.io

fn twice(f: (Int) -> Int, x: Int) -> Int is Pure { f(f(x)) }

fn run(x: Int) -> Int {
  twice({ n ->
    printLine("step")
    n + 1
  }, x)
}
```

## Fixed

```crag
fn twice(f: (Int) -> Int, x: Int) -> Int is Pure { f(f(x)) }

fn run(x: Int) -> Int {
  twice({ n -> n + 1 }, x)
}
```
