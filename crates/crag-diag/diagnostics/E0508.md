---
code: E0508
name: NotAForm
title: A `where` entry that names no form
spec: 4.4
---

An entry of a `where` clause, and of a bound alias, is a form applied to
type parameters, such as `Hash[K]`, or a marker requirement `T is
Solid`. A named type there is not a requirement and is refused.

## Rationale

Forms say what can be done with a type; a named type says what a value
is. To restrict a parameter to a family of types, bound it in brackets,
`[S: Shape]`.

## Failing

```crag
type Shape(x: Int, y: Int)
fn left[S](s: S) -> Int where Shape { 0 }
```

## Fixed

```crag
type Shape(x: Int, y: Int)
fn left[S: Shape](s: S) -> Int { s.x }
```
