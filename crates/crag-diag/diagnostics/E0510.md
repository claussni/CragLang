---
code: E0510
name: GenericLocalFn
title: A local function with type parameters
spec: 5.6.4
---

A `fn` declared inside a block is a local function. It may capture
bindings and call itself, but it has no type parameters.

## Rationale

A local function is a binding of its block, like a closure, so it is
never specialized for several types. Move a generic helper to module
level, or give the local function concrete types.

## Failing

```crag
fn larger(a: Int, b: Int) -> Int {
  fn pick[T](x: T, y: T, first: Bool) -> T { if first { x } else { y } }
  pick(a, b, a >= b)
}
```

## Fixed

```crag
fn pick[T](x: T, y: T, first: Bool) -> T { if first { x } else { y } }
fn larger(a: Int, b: Int) -> Int {
  pick(a, b, a >= b)
}
```
