---
code: E0501
name: FitBound
title: A type argument that does not fit its bound
spec: 4.2
---

A named type may bound a type parameter: `[S: Shape]` admits `Shape` and
every type that spreads it. A type argument outside that family does not
fit, and the call or construction is refused. The message names the
argument, the bound and the parameter.

## Rationale

A type bound lets one function keep the precise type of every member of
a family. Pass a value of the bound type or of a type that spreads it,
or bound the parameter by a form when the types are related only by
their functions.

## Failing

```crag
type Shape(x: Int, y: Int)
type Label(text: Str)
fn left[S: Shape](s: S) -> Int { s.x }
fn main() -> Int { left(Label(text: "a")) }
```

## Fixed

```crag
type Shape(x: Int, y: Int)
type Circle(..Shape, r: Int)
fn left[S: Shape](s: S) -> Int { s.x }
fn main() -> Int { left(Circle(x: 1, y: 2, r: 3)) }
```
