---
code: E0603
name: BindingsOnly
title: A bindings-only value that escapes
spec: 9.2
---

A ref, an `ext` cell, and a closure or `lazy` value that carries one
are bindings-only. They may be passed as arguments to a known function
and called, but never returned, stored in a data structure or a ref,
emitted, or passed to a function whose body the compiler cannot see.

## Rationale

A ref lives only as long as the scope that binds it, so a value that
reaches it must not outlive that scope. Return or store the ref's
value, `r.use()`, instead, or call the closure where it is bound.

## Failing

```crag
fn tally(xs: List[Int]) -> Int {
  ref total = 0
  let add = { n: Int -> total.update { t -> t + n } }
  let jobs = [add]
  total.use()
}
```

## Fixed

```crag
fn tally(xs: List[Int]) -> Int {
  ref total = 0
  let add = { n: Int -> total.update { t -> t + n } }
  for x in xs { add(x) }
  total.use()
}
```
