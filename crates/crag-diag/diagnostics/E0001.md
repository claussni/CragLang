code: E0001
name: Syntax
title: The text does not parse
spec: D
---

The source must follow the grammar of the language. Where the parser
meets a token that no rule allows, it reports what it expected there,
such as "expected an expression" or "expected `)`", and recovers at the
next declaration or line.

## Rationale

The parser reports every place it cannot continue, so one typo can
cause a few errors after it. Fix the first one at the position shown:
add the missing operand or bracket, or remove the stray token.

## Failing

```crag
fn area(width: Int, height: Int) -> Int { width * }
```

## Fixed

```crag
fn area(width: Int, height: Int) -> Int { width * height }
```
