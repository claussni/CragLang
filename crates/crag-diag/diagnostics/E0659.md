---
code: E0659
name: SecretInSignal
title: A signal that holds a secret
spec: 11.1
---

A signal type must not hold a `Secret`, neither as a whole nor in any
field. The message names the field path that holds the secret.

## Rationale

Signals reach handlers far from where they are emitted, and the root
handler prints them to stderr, so a secret would leak. Leave the
secret out of the signal and carry an identifier instead.

## Failing

```crag
distinct type Password(raw: Bytes) is Secret

type LoggedIn(..Signal, user: Str, password: Password)
```

## Fixed

```crag
distinct type Password(raw: Bytes) is Secret

type LoggedIn(..Signal, user: Str)
```
