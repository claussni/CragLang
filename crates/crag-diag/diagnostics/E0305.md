---
code: E0305
name: Ambiguous
title: A call that several functions fit equally well
spec: 5.6.1
---

A call resolves statically to one function. When several functions of
the name take the arguments and none is more specific than the others,
the call is ambiguous. Overloads that differ only in their result type
are told apart by the expected type, so without one they all fit.

## Rationale

Crag has no call-site hints and never picks one of the candidates
arbitrarily. Give the expected type with an annotation on the binding
or a result type, or rename or import selectively one of the clashing
functions.

## Failing

```crag
fn read(s: Str) -> Int | ParseError {
  let n = parse(s)
  n
}
```

## Fixed

```crag
fn read(s: Str) -> Int | ParseError {
  let n: Int | ParseError = parse(s)
  n
}
```
