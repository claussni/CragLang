---
code: E0208
name: NoOperator
title: An operator whose function is not in scope
spec: 6.2
---

Every operator calls a function of a fixed name: `+` calls `add`, `<`
calls `lessThan`, unary `-` calls `negate`. When no function of that
name is in scope at all, the operator is an error. This happens when
an import renames the prelude's function away.

## Rationale

Operators are ordinary functions, so they follow the same scoping as
calls. Keep the prelude's name in scope, or call the renamed function
directly.

## Failing

```crag
import std.core.add as plus

fn total(a: Int, b: Int) -> Int { a + b }
```

## Fixed

```crag
import std.core.add as plus

fn total(a: Int, b: Int) -> Int { plus(a, b) }
```
