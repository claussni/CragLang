---
code: E0701
name: PureCapture
title: An `is Pure` closure that captures a value that is not Solid
spec: 3.11
---

A closure whose type is `is Pure` captures only `Solid` values. A
capture that may fail when it is used, such as a `Lazy`, a ref, an
`ext` binding or a runtime handle, makes the closure impure. The
message names the capture and why its type is not Solid.

## Rationale

A Pure closure must give the same result every time and never fail
through what it holds. Read the value outside the closure and capture
the result, or pass the value in as a parameter.

## Failing

```crag
fn apply(f: ((Int) -> Int is Pure), x: Int) -> Int { f(x) }

fn later(l: Lazy[Int], x: Int) -> Int {
  apply({ n -> n + l.value }, x)
}
```

## Fixed

```crag
fn apply(f: ((Int) -> Int is Pure), x: Int) -> Int { f(x) }

fn later(l: Lazy[Int], x: Int) -> Int {
  let v = l.value
  apply({ n -> n + v }, x)
}
```
