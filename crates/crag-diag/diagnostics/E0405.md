---
code: E0405
name: SpreadInUpdate
title: A spread in the list of an update
spec: 6.7.1
---

`v.update(list)` rebuilds `v` with a field-update list. The value being
rebuilt is `v` itself, so the list holds only fields with values or
transforms, never a spread `..w`.

## Rationale

`update` already starts from `v`, so a spread would either repeat it or
mix in another value's fields. Drop the spread, or build the record with
its constructor, `T(..w, field: value)`, to start from another value.

## Failing

```crag
type Point(x: Int, y: Int)
fn moved(p: Point) -> Point { p.update(..p, x: _ + 1) }
```

## Fixed

```crag
type Point(x: Int, y: Int)
fn moved(p: Point) -> Point { p.update(x: _ + 1) }
```
