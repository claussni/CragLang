---
code: E0403
name: UnknownField
title: A field the record does not declare
spec: 6.7
---

Building or updating a record names only fields its type declares.
A named field that matches no field of the type is refused.

## Rationale

A misspelt field would otherwise be dropped or mistaken for another
one. Check the name against the type's declaration, or add the field to
the type.

## Failing

```crag
type Point(x: Int, y: Int)
fn origin() -> Point { Point(x: 0, y: 0, z: 0) }
```

## Fixed

```crag
type Point(x: Int, y: Int)
fn origin() -> Point { Point(x: 0, y: 0) }
```
