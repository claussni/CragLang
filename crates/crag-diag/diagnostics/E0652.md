---
code: E0652
name: NotALifecycleKind
title: An `on` clause of what is no lifecycle kind
spec: 11.4
---

The kind after `on` must be a lifecycle kind: a type that spreads
`LifecycleHandler` and states a `HandlerForm`. The standard kinds are
`Dispose`, `Encode`, `Decode`, `Migrate` and `Embed`.

## Rationale

The runtime and the standard library call a handler only at points
that a lifecycle kind defines, and the form says what the handler must
look like. Name one of the lifecycle kinds.

## Failing

```crag
distinct type Level(n: Int)
  on Str parseLevel

fn parseLevel(text: Str) -> Level { Level(n: 1) }
```

## Fixed

```crag
distinct type Level(n: Int)
  on Embed parseLevel

fn parseLevel(text: Str) -> Level { Level(n: 1) }
```
