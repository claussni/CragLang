---
code: E0316
name: NotIndexable
title: Indexing a value that cannot be indexed
spec: 6.5
---

`e[i]` indexes lists and grids by position and maps by key. Indexing a
value of any other type is refused. `Str` has no integer indexing,
since a position in UTF-8 text is not a count of characters.

## Rationale

Text positions come from index functions such as `start`, `indexOf`
and `after`, and are used with `codePointAt` and `substring`. Use those,
or index a list, map or grid.

## Failing

```crag
fn initial(name: Str) -> Option[CodePoint] { name[0] }
```

## Fixed

```crag
fn initial(name: Str) -> Option[CodePoint] { name.codePointAt(name.start()) }
```
