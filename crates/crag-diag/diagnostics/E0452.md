---
code: E0452
name: Unreachable
title: A case arm that earlier arms cover
spec: 7.2
---

The arms of a `case` are tried in source order, and the first that
matches wins. An arm whose values all match earlier arms can never run,
and is refused. A guard `where` never makes an arm cover a later one.

## Rationale

An unreachable arm is dead code that usually hides a mistake in the
order: a parent type before its subtype, or `_` before the last arm.
Move the more specific arm first, or delete it.

## Failing

```crag
type LookupError(..Error)
type NotFound(..LookupError)
fn label(r: Int | LookupError) -> Str {
  case r {
    n: Int -> "{n}"
    LookupError -> "lookup failed"
    NotFound -> "missing"
  }
}
```

## Fixed

```crag
type LookupError(..Error)
type NotFound(..LookupError)
fn label(r: Int | LookupError) -> Str {
  case r {
    n: Int -> "{n}"
    NotFound -> "missing"
    LookupError -> "lookup failed"
  }
}
```
