---
code: E0306
name: ArgCount
title: A call with the wrong number of arguments
spec: 5.6
---

A call gives one argument to each parameter of the function, except
the parameters with a default, which it may leave out. A call with more
arguments than the function has parameters, or with fewer than it
needs, is refused.

## Rationale

A call's arguments are matched to the parameters by position and by
name, so a surplus argument has no place to go. Remove it, or call the
function that takes that many.

## Failing

```crag
fn area(width: Int, height: Int) -> Int { width * height }
fn room() -> Int { area(3, 4, 5) }
```

## Fixed

```crag
fn area(width: Int, height: Int) -> Int { width * height }
fn room() -> Int { area(3, 4) }
```
