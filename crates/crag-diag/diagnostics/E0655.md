---
code: E0655
name: DisposeOfNoBox
title: An `on Dispose` handler on a type that is not a record
spec: 11.5
---

Only a record type takes an `on Dispose` handler. A `distinct` type
declared without fields is no record, so its values have no lives that
end.

## Rationale

A dispose handler runs when a value is removed, and only a record is a
box with a life of its own. Give the type fields, or drop the
handler.

## Failing

```crag
distinct type Token
  on Dispose closeToken

fn closeToken(t: Token) -> () {}
```

## Fixed

```crag
distinct type Token(id: Int)
  on Dispose closeToken

fn closeToken(t: Token) -> () {}
```
