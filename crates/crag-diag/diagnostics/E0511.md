---
code: E0511
name: GenericSlot
title: A form's function with type parameters of its own
spec: 4.1
---

A form's functions have no type parameters of their own. Every type a
form relates is one of the form's parameters, which are all
independent.

## Rationale

A form's function is filled by one visible function per type argument,
so a type it does not fix cannot be looked up. Make the type a
parameter of the form, as in `form Container[C, T]`.

## Failing

```crag
form Container[C] {
  size[T](c: C) -> Int
}
```

## Fixed

```crag
form Container[C] {
  size(c: C) -> Int
}
```
