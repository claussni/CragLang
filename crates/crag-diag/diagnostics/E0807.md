---
code: E0807
name: DurNeedsType
title: A `dur` binding without a type annotation
spec: 21.2
---

A `dur` binding requires its type annotation: it is the schema of the
slot. The annotation names the value type `T`; the binding's type is
`Dur[T]`, and the initializer is checked against `Slot[T] | StoreError`
(§21.2).

## Rationale

The slot's value type is a durable contract with the store, not a
detail of one program run. Inferring it from the initializer would let
an edit far from the binding change what the store holds, and migration
(§21.8) could not tell a schema change from an inference change.

## Failing

```crag
fn f(s: Slot[Int] | StoreError) -> () | StoreError {
  dur n = s else { e -> return e }
}
```

## Fixed

```crag
fn f(s: Slot[Int] | StoreError) -> () | StoreError {
  dur n: Int = s else { e -> return e }
}
```
