---
code: E0805
name: NotFlat
title: A type marked `is Flat` that is boxed
spec: 3.11
---

`is Flat` asserts that a type's values are stored inline, not behind a
pointer. A type that would be boxed anyway is an error at its
declaration: it is too large (more than 32 bytes or 2 managed
pointers), or it has a lifecycle, as a `Secret` type does. For a
generic type, every instance the program uses is checked.

## Rationale

The marker guards a layout you rely on for speed, so the compiler says
when it cannot hold. Use smaller field types, split the type, or drop
`is Flat`.

## Failing

```crag
type Pixel(x: Int, y: Int, red: Int, green: Int, blue: Int)
  is Flat
```

## Fixed

```crag
type Pixel(x: Int, y: Int, red: UInt8, green: UInt8, blue: UInt8)
  is Flat
```
