---
code: E0806
name: BindElse
title: An `else` part on a binding that takes none
spec: 21.2
---

Of the binding kinds, only `dur` takes an `else` part: its initializer
produces `Slot[T] | StoreError`, and the `else` part receives the error
and must leave (§21.2, §7.1.1). A `ref` or `var` initializer cannot
fail, so an `else` part on one is an error. The `else` part of an `ext`
binding (§23.3.1) is not supported yet.

## Rationale

An `else` part exists to take the initializer's error members off the
binding. A binding whose initializer has no error members has nothing
for it to receive.

## Failing

```crag
fn f() -> Int {
  ref n = 0 else { return 1 }
  n.use()
}
```

## Fixed

```crag
fn f() -> Int {
  ref n = 0
  n.use()
}
```
