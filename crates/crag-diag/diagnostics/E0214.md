---
code: E0214
name: MisplacedMarker
title: A marker where only `Pure` may stand
spec: 3.14
---

A function, or a function type inside parentheses, may be marked
`is Pure`: it performs no effects. No other marker may stand there,
and `is Pure` on a type that is not a function type is an error too.
Markers such as `Solid` describe types and are required of type
parameters with `where`.

## Rationale

Effects are inferred, and `is Pure` is the only restriction a
signature can write. Write `is Pure`, or move another marker to a
`where` clause on a type parameter.

## Failing

```crag
fn square(x: Int) -> Int is Solid { x * x }
```

## Fixed

```crag
fn square(x: Int) -> Int is Pure { x * x }
```
