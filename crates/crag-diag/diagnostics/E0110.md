---
code: E0110
name: Redeclared
title: A name declared again: Crag has no shadowing
spec: 5.4
---

Redeclaring a name already in scope is never allowed. A binding may
not take the name of another binding of the same body, nor of a
declaration in scope, such as a type of the module or the prelude.
Only a `var` can be given a new value, and it keeps its name.

## Rationale

Without shadowing a name means one thing throughout its scope, so a
reader never has to find which declaration is in effect. Pick a new
name for the new value, or declare a `var` and assign it.

## Failing

```crag
fn total(price: Int) -> Int {
  let sum = price
  let sum = sum + 1
  sum
}
```

## Fixed

```crag
fn total(price: Int) -> Int {
  let sum = price
  let withFee = sum + 1
  withFee
}
```
