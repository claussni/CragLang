---
code: E0205
name: BadLiteral
title: A literal that is malformed
spec: 2.6
---

A literal must be well formed: digits valid for its base, and only
the escapes `\n`, `\t`, `\r`, `\0`, `\\`, `\"`, `\'` and `\u{…}` in
strings and code points, plus `\xHH` in byte literals. An unknown
escape or a malformed number is an error.

## Rationale

Unknown escapes are refused rather than kept literally, so a typo never
changes a string silently. Escape a backslash as `\\`, and check the
digits of a hexadecimal, binary or octal number.

## Failing

```crag
fn folder() -> Str { "C:\temp\queue" }
```

## Fixed

```crag
fn folder() -> Str { "C:\\temp\\queue" }
```
