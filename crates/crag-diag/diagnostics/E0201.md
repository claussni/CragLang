---
code: E0201
name: Undefined
title: A name that is not defined
spec: 5.4
---

Every name in an expression must refer to a binding in scope, a
declaration of the module, or an imported or prelude element. A name
that none of these define is an error.

## Rationale

Crag resolves names before it infers types, so a misspelt name is
caught where it is written. Check the spelling, declare the binding
first, or import the module that declares it.

## Failing

```crag
fn area(width: Int, height: Int) -> Int { width * heigth }
```

## Fixed

```crag
fn area(width: Int, height: Int) -> Int { width * height }
```
