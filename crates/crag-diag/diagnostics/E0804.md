---
code: E0804
name: EmbedFails
title: An `embed` whose handler gives an error
spec: 18.4.1
---

An `on Embed` handler runs at compile time on the resource. When it
returns an `EmbedError`, the `embed` is an error. The message carries
the handler's message and, when given, the line and column in the
resource.

## Rationale

A resource is source, so a resource the handler rejects is a compile
error like a typo in code. Fix the resource at the place the message
names, or make the handler accept it.

## Failing

```crag
distinct type Level(n: Int)
  on Embed parseLevel

fn parseLevel(text: Str) -> Level | EmbedError {
  case text.trim() {
    "low" -> Level(n: 1)
    "high" -> Level(n: 3)
    _ -> EmbedError(message: "expected low or high", line: 1, column: 1)
  }
}

embed level: Level from "level.txt"
// file: level.txt
medium
```

## Fixed

```crag
distinct type Level(n: Int)
  on Embed parseLevel

fn parseLevel(text: Str) -> Level | EmbedError {
  case text.trim() {
    "low" -> Level(n: 1)
    "high" -> Level(n: 3)
    _ -> EmbedError(message: "expected low or high", line: 1, column: 1)
  }
}

embed level: Level from "level.txt"
// file: level.txt
high
```
