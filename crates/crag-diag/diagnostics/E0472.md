---
code: E0472
name: RecursiveGroup
title: A recursive group without its success types
spec: 3.13.1
---

A recursive function, and each member of a group of mutually recursive
functions, states its success type. Functions form a group when
inferring their success types depends on each other, including through
every overload of a name a call must compare. The message names the
call that links the group and every member missing a success type.

## Rationale

Inference is local and cannot solve a function's type from its own
body. Write the success type on each member the message names; the
errors stay inferred.

## Failing

```crag
fn isEven(n: Int) { if n == 0 { True } else { isOdd(n - 1) } }
fn isOdd(n: Int) { if n == 0 { False } else { isEven(n - 1) } }
```

## Fixed

```crag
fn isEven(n: Int) -> Bool { if n == 0 { True } else { isOdd(n - 1) } }
fn isOdd(n: Int) -> Bool { if n == 0 { False } else { isEven(n - 1) } }
```
