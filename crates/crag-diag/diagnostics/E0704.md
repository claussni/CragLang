---
code: E0704
name: CellCapture
title: Code sent as an `Expr` that captures a `ref` or an `ext`
spec: 18.6
---

A closure literal that becomes an `Expr` may not capture a `ref` or an
`ext` binding from around it. These are bindings to a cell or a
resource, not values, so there is nothing to copy into the `Expr`.

## Rationale

A receiver has no access to the sender's cells and resources. Read the
current value before building the closure, bind it with `let`, and
capture that value instead.

## Failing

```crag
import std.transport

fn send(job: Expr[((Int) -> Int is Pure)]) -> Int { job(1) }

fn total() -> Int {
  ref step = 2
  send({ n -> n + step })
}
```

## Fixed

```crag
import std.transport

fn send(job: Expr[((Int) -> Int is Pure)]) -> Int { job(1) }

fn total() -> Int {
  ref step = 2
  let now = step.use { s -> s }
  send({ n -> n + now })
}
```
