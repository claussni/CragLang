---
code: E0309
name: NotCallable
title: A call of a value that is not a function
spec: 3.7
---

Only a value of a function type can be called. Calling a value of any
other type, such as a number or a record, is refused, and the message
names its type.

## Rationale

This often happens when a local binding shadows a function of the same
name, or when an operator is missing, as in `2(n)` for `2 * n`. Rename
the binding, or write the operator.

## Failing

```crag
fn twice(n: Int) -> Int {
  let step = 2
  step(n)
}
```

## Fixed

```crag
fn twice(n: Int) -> Int {
  let step = 2
  step * n
}
```
