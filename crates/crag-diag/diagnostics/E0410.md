---
code: E0410
name: AliasCycle
title: An alias that refers to itself
spec: 3.5
---

`type X = T` makes `X` another name for `T`. Following the aliases must
end in a type that is not an alias. An alias that leads back to itself,
directly or through other aliases, names no type.

## Rationale

An alias is replaced by what it names, so a cycle of aliases never ends.
A recursive type needs a record in the cycle, as in
`type Tree(left: Tree | Leaf, right: Tree | Leaf)`. Point one of the
aliases at a real type.

## Failing

```crag
type UserId = AccountId
type AccountId = UserId
```

## Fixed

```crag
type UserId = AccountId
type AccountId = Int
```
