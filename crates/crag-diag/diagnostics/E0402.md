---
code: E0402
name: MissingField
title: A record built without one of its fields
spec: 6.7
---

Building a record names a value for every field that has no default.
A spread `..v` supplies the fields of `v`, and a field with a default
may be left out. A field that gets no value from any of these is
missing.

## Rationale

A record value always has all its fields, so there is no partly built
record and no null. Give the field a value, spread a value that has it,
or give the field a default in the type's declaration.

## Failing

```crag
type Point(x: Int, y: Int)
fn onAxis(x: Int) -> Point { Point(x: x) }
```

## Fixed

```crag
type Point(x: Int, y: Int)
fn onAxis(x: Int) -> Point { Point(x: x, y: 0) }
```
