---
code: E0324
name: RaggedGrid
title: Grid rows of different widths
spec: 12.3
---

A grid literal separates its rows with `;`, and every row must have
as many cells as the first. A row with more or fewer cells is refused,
and the message names the row and both widths.

## Rationale

A `Grid[T]` is a strict two-dimensional matrix, so its columns must
line up. Fill the short row, or use a `List[List[T]]` for rows of
different lengths.

## Failing

```crag
fn board() -> Grid[Int] { [1, 2, 3; 4, 5] }
```

## Fixed

```crag
fn board() -> Grid[Int] { [1, 2, 3; 4, 5, 6] }
```
