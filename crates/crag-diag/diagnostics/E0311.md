---
code: E0311
name: UninferredTypeArg
title: A type parameter that cannot be inferred
spec: 3.13.2
---

A generic call's type parameters come from its arguments and its
expected result. When a type parameter appears in neither, or a generic
function is used as a value with no expected function type, the
compiler cannot choose it.

## Rationale

Type parameters are never guessed or defaulted. Give the expected type
with an annotation, or write the type arguments in brackets, as in
`fresh[Int]()`.

## Failing

```crag
fn fresh[T]() -> List[T] { [] }

fn count() -> Int {
  let xs = fresh()
  0
}
```

## Fixed

```crag
fn fresh[T]() -> List[T] { [] }

fn count() -> Int {
  let xs: List[Int] = fresh()
  0
}
```
