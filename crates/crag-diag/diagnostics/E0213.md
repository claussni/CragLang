---
code: E0213
name: ExpectedValue
title: A type where a value is expected
spec: 6.5
---

`e[…]` supplies type arguments when `e` is a type, a form or a
function, and indexes otherwise. When it indexes a value, its
arguments are values; a function type, a union or an `is` clause
there is an error.

## Rationale

Bracket application decides from `e` what the brackets hold, so a
type in an index is a mistake. Index with a value, such as a
position or a key.

## Failing

```crag
fn first(xs: List[Int]) -> Int { xs[Int | Str] }
```

## Fixed

```crag
fn first(xs: List[Int]) -> Int { xs[0] }
```
