---
code: E0211
name: MisplacedSpread
title: A spread that is not the first entry of a field list
spec: 3.8
---

A named type may amend exactly one parent by spreading it as the first
entry of its field list: `type Circle(..Shape, radius: Int)`. A spread
in any other place, or a second spread, is an error.

## Rationale

A type has at most one parent, and putting it first makes the parent
visible at a glance. Move the spread to the front, and keep one.

## Failing

```crag
type Shape(name: Str)
type Circle(radius: Int, ..Shape)
```

## Fixed

```crag
type Shape(name: Str)
type Circle(..Shape, radius: Int)
```
