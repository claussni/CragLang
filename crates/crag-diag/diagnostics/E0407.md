---
code: E0407
name: ConditionNotMet
title: A value the compiler sees failing a condition
spec: 3.10.1
---

A type alias may carry a `where` condition, which makes a checked subset
of a type. A value known at compile time, such as a literal, may stand
where the alias is expected when it meets the condition. When the
compiler evaluates the condition and it fails, the value is refused.

## Rationale

A failure the compiler can see is reported where it is written, not as
a trap at run time. The message names the condition; change the value,
or widen the condition if the value should be allowed.

## Failing

```crag
type Percent = Int where this >= 0 and this <= 100
fn full() -> Percent { 150 }
```

## Fixed

```crag
type Percent = Int where this >= 0 and this <= 100
fn full() -> Percent { 100 }
```
