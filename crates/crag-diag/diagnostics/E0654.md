---
code: E0654
name: HandlerDoesNotFit
title: A handler function that does not fit its form
spec: 11.4
---

A handler named in an `on` clause must fit the form of its kind, the
parameter and result types its `HandlerForm` prescribes. The kind's
type parameter is the declaring type. The message shows the form.

## Rationale

The runtime calls the handler with the arguments the form names and
uses its result, so other types cannot work. Change the function's
parameters or result to match the form in the message.

## Failing

```crag
distinct type Level(n: Int)
  on Embed parseLevel

fn parseLevel(n: Int) -> Level { Level(n: n) }
```

## Fixed

```crag
distinct type Level(n: Int)
  on Embed parseLevel

fn parseLevel(text: Str) -> Level { Level(n: 1) }
```
