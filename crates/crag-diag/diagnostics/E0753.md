---
code: E0753
name: UndeclaredLibrary
title: A C library the package does not declare
spec: 16.1
---

`cLib("L")` names a native library that the package manifest declares
with `native L "file", …`. A name the manifest does not declare is an
error at the import.

## Rationale

The manifest lists every native library so the build and the SBOM know
what the program loads. Add a `native` line for the library to
`package.crag`, then run `crag package sbom regenerate`.

## Failing

```crag
import cLib("m").{ cos(x: Float) -> Float } is ThreadSafe
```

## Fixed

```crag
import cLib("m").{ cos(x: Float) -> Float } is ThreadSafe
// file: package.crag
package demo 0.1
runtime 0.0
native m "libm.so.6"
// file: sbom.crag
native demo m "libm.so.6"
```
