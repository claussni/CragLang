---
code: E0307
name: UnknownParam
title: A named argument that names no parameter
spec: 5.6
---

A named argument `name: value` gives the parameter of that name. When
the called function has no parameter of the name, the argument is
refused. A closure's parameters have no names of their own, so a
function value takes only positional arguments.

## Rationale

A misspelt name would otherwise pass a value to nowhere or silently
fall back to a default. Use the parameter's name as the function
declares it.

## Failing

```crag
fn greet(name: Str, greeting: Str = "Hello") -> Str { "{greeting}, {name}" }
fn morning() -> Str { greet("Ada", salute: "Morning") }
```

## Fixed

```crag
fn greet(name: Str, greeting: Str = "Hello") -> Str { "{greeting}, {name}" }
fn morning() -> Str { greet("Ada", greeting: "Morning") }
```
