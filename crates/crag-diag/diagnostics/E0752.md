---
code: E0752
name: ThreadingMismatch
title: A C library imported with different thread-safety markers
spec: 16.4
---

Every import of one C library states the same thread-safety marker:
`ThreadSafe`, `ThreadUnsafe` or `ThreadBound`. Imports that differ are
an error at each of them, naming the other module.

## Rationale

The marker describes the library, not one import, and the runtime
calls the library under one discipline. Find out which marker the
library deserves and write it on every import.

## Failing

```crag
import cLib("m").{ cos(x: Float) -> Float } is ThreadSafe
// file: geo.crag
import cLib("m").{ sin(x: Float) -> Float } is ThreadUnsafe
// file: package.crag
package demo 0.1
runtime 0.0
native m "libm.so.6"
// file: sbom.crag
native demo m "libm.so.6"
```

## Fixed

```crag
import cLib("m").{ cos(x: Float) -> Float } is ThreadSafe
// file: geo.crag
import cLib("m").{ sin(x: Float) -> Float } is ThreadSafe
// file: package.crag
package demo 0.1
runtime 0.0
native m "libm.so.6"
// file: sbom.crag
native demo m "libm.so.6"
```
