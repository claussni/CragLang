---
code: E0515
name: MarkerNotAType
title: A marker used as a type
spec: 4.2
---

A marker such as `Solid` or `Secret` is a constraint on a type, not a
type. It cannot be the type of a parameter, field or binding; only a
requirement may name it, as in `where T is Solid`.

## Rationale

A form can stand for a type parameter in parameter position, but a
marker cannot: values have exactly one concrete type, and markers come
from it. Add a type parameter and require the marker of it.

## Failing

```crag
fn cache(x: Solid) -> () {}
```

## Fixed

```crag
fn cache[T](x: T) -> () where T is Solid {}
```
