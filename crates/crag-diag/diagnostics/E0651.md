---
code: E0651
name: HandlerOnStructural
title: A lifecycle handler on a structural type
spec: 11.4
---

An `on` clause attaches a lifecycle handler to a type, and only a
nominal type takes one: a `distinct` or an `opaque` type. A plain
`type` is structural.

## Rationale

Structural types with the same fields are the same type, so two
declarations could merge into one type with two handlers. Declare the
type `distinct` or `opaque`.

## Failing

```crag
type Level(n: Int)
  on Embed parseLevel

fn parseLevel(text: Str) -> Level { Level(n: 1) }
```

## Fixed

```crag
distinct type Level(n: Int)
  on Embed parseLevel

fn parseLevel(text: Str) -> Level { Level(n: 1) }
```
