---
code: E0319
name: Decreasing
title: A range whose first end exceeds its last
spec: 7.4
---

A range `a..b` runs upward from `a` to `b` and is never empty, so `a`
must not exceed `b`. A range whose two ends are constants and decrease
is refused at compile time. A decreasing range with ends known only at
run time traps.

## Rationale

A decreasing range is almost always a mistake, such as swapped ends.
Swap the ends. A countdown iterates the increasing range and computes
each value from it.

## Failing

```crag
fn countdown() -> Int {
  var t = 0
  for i in 10..1 { t = t + i }
  t
}
```

## Fixed

```crag
fn countdown() -> Int {
  var t = 0
  for i in 1..10 { t = t + i }
  t
}
```
