---
code: E0303
name: NoMatch
title: No function of the name takes the arguments
spec: 5.6.1
---

A call resolves to a function of its name, or an operator to its
function, whose parameters take the arguments' types. When none does,
the call is refused and the message lists the argument types it tried.
Method syntax `x.f(y)` is a call `f(x, y)`, so the receiver is the first
argument.

## Rationale

Overloads are resolved by argument types, and operators are functions
such as `multiply` and `add`. Look up the functions of the name with
`searchStd` or `members`, then convert an argument or call another
function.

## Failing

```crag
fn double(x: Int) -> Int { x * "2" }
```

## Fixed

```crag
fn double(x: Int) -> Int { x * 2 }
```
