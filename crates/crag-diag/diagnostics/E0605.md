---
code: E0605
name: SecondRef
title: An `update` closure that resolves another ref
spec: 9.5
---

An `update` closure resolves only the ref it updates. Reading a second
ref inside it is an error. To read or change several refs together,
use an `atomic` block.

## Rationale

An update is optimistic: it commits only if its own ref did not change,
so a second ref read inside it could be stale by the commit. An
`atomic` block tracks every ref it touches and commits them together.

## Failing

```crag
fn transfer(amount: Int) -> Int {
  ref from = 100
  ref to = 0
  to.update { b -> if from.use() >= amount { b + amount } else { b } }
  to.use()
}
```

## Fixed

```crag
fn transfer(amount: Int) -> Int {
  ref from = 100
  ref to = 0
  atomic {
    if from.use() >= amount {
      from.update { b -> b - amount }
      to.update { b -> b + amount }
    }
  }
  to.use()
}
```
