---
code: E0706
name: SecretCapture
title: Code sent as an `Expr` that captures a secret
spec: 18.6
---

A closure literal that becomes an `Expr` may not capture a value that
holds a `Secret`, directly or in a field. A module-level binding the
body reads counts as a capture. The message names the capture, and the
field when the secret sits inside it.

## Rationale

An `Expr` carries its captures to another node, and a secret must never
leave the program that way. Keep the secret on the sending side and
send only values derived from public data.

## Failing

```crag
import std.transport

type ApiKey(raw: Str) is Secret

fn send(job: Expr[((Str) -> Bool is Pure)]) -> Bool { job("") }

fn check(key: ApiKey) -> Bool {
  send({ given -> given == key.raw })
}
```

## Fixed

```crag
import std.transport

type ApiKey(raw: Str) is Secret

fn send(job: Expr[((Str) -> Bool is Pure)]) -> Bool { job("") }

fn check(prefix: Str) -> Bool {
  send({ given -> given.startsWith(prefix) })
}
```
