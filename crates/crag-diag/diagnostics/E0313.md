---
code: E0313
name: TypeArgKind
title: A type argument of the wrong kind
spec: 3.1.2
---

`Fixed[S]` takes the number of decimal digits as its argument, as in
`Fixed[2]`, and every other generic type takes types. A type given to
`Fixed`, or a number given to a type parameter that takes a type, is
refused.

## Rationale

The scale of a fixed-point number is a count of digits, not a type. Write
the number of decimals the values need, as in `Fixed[2]` for money.

## Failing

```crag
fn price(amount: Fixed[Int]) -> Fixed[2] { 1.00 }
```

## Fixed

```crag
fn price(amount: Fixed[2]) -> Fixed[2] { amount }
```
