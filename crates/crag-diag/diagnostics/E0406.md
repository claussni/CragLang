---
code: E0406
name: NoCurrentValue
title: A transform of a field that has no current value
spec: 6.7
---

A field override may be a transform, a function from the field's type
to itself such as `_ + 1`, which changes the field's current value. A
current value comes only from a spread `..v` or from the value an
`update` rebuilds. Without one, the transform has nothing to change.

## Rationale

A transform reads the old value, so a record built from scratch cannot
take one. Spread a value that has the field, or give the field a plain
value.

## Failing

```crag
type Counter(count: Int, step: Int)
fn start() -> Counter { Counter(count: _ + 1, step: 1) }
```

## Fixed

```crag
type Counter(count: Int, step: Int)
fn next(c: Counter) -> Counter { Counter(..c, count: _ + c.step) }
```
