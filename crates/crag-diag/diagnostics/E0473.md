---
code: E0473
name: ValueCycle
title: A module-level value that depends on itself
spec: 5.5
---

A module-level `let` is evaluated at compile time or once on first use,
from the values and functions it names. When computing it needs the
value itself, directly, through other values or through a function it
calls, it has no value to start from.

## Rationale

A value cycle never ends, so it is refused instead of hanging or
reading an unset value. Compute one of the values without the others,
or turn the computation into a function with parameters.

## Failing

```crag
let width = height * 2
let height = width / 2
```

## Fixed

```crag
let height = 40
let width = height * 2
```
