---
code: E0207
name: UnknownPrefix
title: Prefix symbols that no declared prefixes make up
spec: 8.5
---

A prefix applies a type mapping function to the expression after it,
such as `~` for `discard`, `?` for `check` and `!!` for `expect`. A
run of prefix symbols must split into prefixes that are declared and
in scope. A run that does not, such as `!` or `!!!`, is an error.

## Rationale

Prefixes are declared, not built in, and the longest match wins, so
an unknown run cannot be guessed. Use a declared prefix; for logical
negation write `not`.

## Failing

```crag
fn port(text: Str) -> Int { !!! Int.parse(text) }
```

## Fixed

```crag
fn port(text: Str) -> Int { !! Int.parse(text) }
```
