---
code: E0408
name: ConditionUndecided
title: A condition the compiler cannot decide for a literal
spec: 3.10.1
---

A literal may stand where a conditioned alias is expected only when the
compiler can evaluate the alias's condition for it. A condition that
calls a function the compiler does not evaluate stays undecided, and
the literal is refused. Such a value enters the alias through the
conversion `T(x)`, which returns `T | Invalid`.

## Rationale

The alias promises that every value of it meets the condition, so an
unchecked value cannot enter it. Convert with `T(x)` and handle
`Invalid`, as the message suggests.

## Failing

```crag
type Name = Str where this.byteCount() > 0
fn greet(who: Name) -> Str { "hi {who}" }
fn hello() -> Str { greet("ada") }
```

## Fixed

```crag
type Name = Str where this.byteCount() > 0
fn greet(who: Name) -> Str { "hi {who}" }
fn hello() -> Str {
  case Name("ada") {
    n: Name -> greet(n)
    Invalid -> "hi"
  }
}
```
