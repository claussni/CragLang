---
code: E0308
name: MissingArg
title: A parameter without a default that no argument gives
spec: 5.6
---

Each parameter of a called function needs a value: an argument, by
position or by name, or the parameter's default. When a parameter has
no default and the call gives no argument for it, the call is refused,
and the message names the parameter.

## Rationale

Only a default can stand in for a missing argument. Pass the argument,
or give the parameter a default in the function's declaration.

## Failing

```crag
fn greet(name: Str, greeting: Str = "Hello") -> Str { "{greeting}, {name}" }
fn morning() -> Str { greet(greeting: "Morning") }
```

## Fixed

```crag
fn greet(name: Str, greeting: Str = "Hello") -> Str { "{greeting}, {name}" }
fn morning() -> Str { greet("Ada", greeting: "Morning") }
```
