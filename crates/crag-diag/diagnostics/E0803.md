---
code: E0803
name: ConstantFails
title: A constant whose evaluation at compile time fails
spec: 18.4
---

Module-level `let` bindings are computed at compile time. When the
computation traps, for example by dividing by zero or failing a
condition, the binding is an error. The message says how it trapped
and in which function.

## Rationale

A constant that cannot be computed would fail every run of the
program, so the compiler reports it before the program starts. Fix the
input or the function so the computation succeeds.

## Failing

```crag
fn share(total: Int, people: Int) -> Int { total / people }

let perPerson = share(120, 0)
```

## Fixed

```crag
fn share(total: Int, people: Int) -> Int { total / people }

let perPerson = share(120, 4)
```
