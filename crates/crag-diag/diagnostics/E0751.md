---
code: E0751
name: NotCType
title: A type that is no C type in a C function
spec: 16.1
---

The parameters and results of an imported C function have C types:
sized integers, `Float`, `CF32`, `CPtr[T]`, `CStr` and `Option[CStr]`.
A result may also be `Str`, `Option[Str]` or `()`. An out parameter
`COut[T]` points only to a sized integer, `Float`, `CF32` or `CPtr[T]`.

## Rationale

A C function sees raw machine values, and Crag values such as lists or
records have no C layout. Pass a pointer and a length, or wrap the call
in a Crag function that converts the data.

## Failing

```crag
import cLib("m").{ hypot(sides: List[Float]) -> Float } is ThreadSafe
// file: package.crag
package demo 0.1
runtime 0.0
native m "libm.so.6"
// file: sbom.crag
native demo m "libm.so.6"
```

## Fixed

```crag
import cLib("m").{ hypot(x: Float, y: Float) -> Float } is ThreadSafe
// file: package.crag
package demo 0.1
runtime 0.0
native m "libm.so.6"
// file: sbom.crag
native demo m "libm.so.6"
```
