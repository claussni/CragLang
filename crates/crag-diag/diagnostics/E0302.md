---
code: E0302
name: LiteralDoesNotFit
title: A literal that does not fit its type
spec: 2.6
---

A number literal takes its type from the context, and its value must
fit that type. An integer literal must lie within the range of its
sized integer type, and a decimal literal for a `Fixed[S]` may have at
most `S` decimals.

## Rationale

The compiler knows a literal's value, so a literal that would overflow
or lose digits is refused before the program runs. Write a value that
fits, or give the place a wider type such as `Int16` or a larger scale.

## Failing

```crag
fn level() -> Int8 { 200 }
```

## Fixed

```crag
fn level() -> Int16 { 200 }
```
