---
code: E0315
name: NoConversion
title: No `convert` between the types
spec: 5.6
---

A type name applied to one unnamed argument, `T(x)`, is a conversion:
it calls the `convert` that takes `x` and returns `T`. When no function
named `convert` is in scope at all, for example after the prelude's
`convert` was renamed with `as`, the conversion has nothing to call.

## Rationale

A conversion is an ordinary call of `convert`, so it follows the names
in scope. Call the renamed function by its new name, or declare a
`convert` for the types.

## Failing

```crag
import std.core.convert as widen

fn wide(n: Int8) -> Int16 { Int16(n) }
```

## Fixed

```crag
import std.core.convert as widen

fn wide(n: Int8) -> Int16 { widen(n) }
```
