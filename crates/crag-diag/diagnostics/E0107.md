---
code: E0107
name: ModuleBesideDirectory
title: A module file beside a directory of the same name
spec: 14.1
---

A module file and a directory in the same directory may not share a
name: `geo.crag` beside `geo/` is an error. Otherwise `demo.geo` could
mean the module or the directory.

## Rationale

The rule gives every import path exactly one reading. Rename the file
or the directory, or move the module into the directory, for example
`geo/plane.crag`.

## Failing

```crag
import demo.geo

fn main() -> Int { area(2) }
// file: geo.crag
pub fn area(side: Int) -> Int { side * side }
// file: geo/solid.crag
pub fn volume(side: Int) -> Int { side * side * side }
```

## Fixed

```crag
import demo.geo

fn main() -> Int { area(2) }
// file: geo/plane.crag
pub fn area(side: Int) -> Int { side * side }
// file: geo/solid.crag
pub fn volume(side: Int) -> Int { side * side * side }
```
