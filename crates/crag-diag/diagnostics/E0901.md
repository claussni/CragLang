---
code: E0901
name: Unsupported
title: Something the compiler does not support yet
spec: 1.2
---

Some programs the specification allows are not implemented yet. The
compiler refuses them with this code instead of guessing, and the
message names what is missing, such as spreads of non-records or
lifted calls whose arguments are typed differently per member.

## Rationale

The program is not wrong, only ahead of the compiler. Write it another
way: here, narrow the union with `is` and make one call per member
instead of relying on union lifting.

## Failing

```crag
type Circle(r: Int)
type Rect(w: Int, h: Int)

fn label(c: Circle, width: Int) -> Str { "circle {c.r}" }
fn label(r: Rect, width: Float) -> Str { "rect {r.w}x{r.h}" }

fn show(s: Circle | Rect) -> Str { label(s, 10) }
```

## Fixed

```crag
type Circle(r: Int)
type Rect(w: Int, h: Int)

fn label(c: Circle, width: Int) -> Str { "circle {c.r}" }
fn label(r: Rect, width: Float) -> Str { "rect {r.w}x{r.h}" }

fn show(s: Circle | Rect) -> Str {
  if s is Circle { label(s, 10) } else { label(s, 10.0) }
}
```
