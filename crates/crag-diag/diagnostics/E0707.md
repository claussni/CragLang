---
code: E0707
name: PrivateExpr
title: A function passed as an `Expr` that is not `pub`
spec: 18.6
---

A named top-level function passed where an `Expr` is expected travels
as a reference, so it must be `pub`. A function without `pub` is an
error at the argument.

## Rationale

A receiver resolves the reference by package, module and name, and it
never sees another module's private names. Mark the function `pub`, or
pass a closure literal that calls it, which bundles it as a helper.

## Failing

```crag
import std.transport

fn adult(age: Int) -> Bool { age >= 18 }

fn send(rule: Expr[((Int) -> Bool is Pure)]) -> Bool { rule(20) }

fn run() -> Bool { send(adult) }
```

## Fixed

```crag
import std.transport

pub fn adult(age: Int) -> Bool { age >= 18 }

fn send(rule: Expr[((Int) -> Bool is Pure)]) -> Bool { rule(20) }

fn run() -> Bool { send(adult) }
```
