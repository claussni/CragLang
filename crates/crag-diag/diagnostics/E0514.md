---
code: E0514
name: OutranksFinal
title: An overload more specific than a `final` one
spec: 5.6.1
---

A function marked `final` cannot be outranked. An overload in scope
that is more specific than a `final` function is an error, in the
`final` function's own module and in any module that imports both.

## Rationale

`final` guards a function whose callers must get exactly it, such as a
check of a signature. Rename the other function, or, when an import
brings it, import one of them selectively or rename it with `as`.

## Failing

```crag
final fn verify[T](x: T, mac: Bytes) -> Bool { True }
fn verify(x: Str, mac: Bytes) -> Bool { False }
```

## Fixed

```crag
final fn verify[T](x: T, mac: Bytes) -> Bool { True }
fn verifyText(x: Str, mac: Bytes) -> Bool { False }
```
