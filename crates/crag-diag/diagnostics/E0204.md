---
code: E0204
name: UnnamedField
title: A record literal element without a name
spec: 2.6
---

An anonymous record has named fields only: `(x: 1, y: 2)`. An element
without a name in a record literal is an error. Positional arguments
belong to calls, such as a named type's constructor.

## Rationale

Records are structural and their fields are matched by name, so an
unnamed value has no field to go into. Write the field's name, or call
a named type's constructor.

## Failing

```crag
fn main() -> Int {
  let point = (x: 0, 0)
  point.x
}
```

## Fixed

```crag
fn main() -> Int {
  let point = (x: 0, y: 0)
  point.x
}
```
