---
code: E0601
name: Effect
title: An effect where the context forbids it
spec: 3.14
---

An `is Pure` function, compile-time code and a field default allow no
effects. An `atomic` block and an `update` closure allow only `ref` and
`signal`: no `io`, and no access to an `ext`. The message names the
effect and the context that refuses it.

## Rationale

A Pure function can run at compile time and be cached, and a
transaction may rerun, so I/O there would happen at the wrong time or
twice. Move the effect out of the restricted context, or emit a signal
and do the I/O in its handler.

## Failing

```crag
import std.io

fn area(w: Int, h: Int) -> Int is Pure {
  printLine("computing area")
  w * h
}
```

## Fixed

```crag
fn area(w: Int, h: Int) -> Int is Pure {
  w * h
}
```
