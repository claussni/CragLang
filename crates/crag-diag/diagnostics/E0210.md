---
code: E0210
name: VarWrittenInClosure
title: A `var` assigned inside a closure that captures it
spec: 6.4.1
---

A closure may read a captured `var` but must never write it. An
assignment to a `var` of an enclosing scope inside a closure is an
error.

## Rationale

A closure can run later or in another task, so writing a captured
`var` would make its value depend on when the closure runs. Write the
loop with `for`, or compute the value with a function such as `fold`.

## Failing

```crag
fn countBig(xs: List[Int]) -> Int {
  var n = 0
  let big = xs.filter { x ->
    n = n + 1
    x > 10
  }
  n
}
```

## Fixed

```crag
fn countBig(xs: List[Int]) -> Int {
  var n = 0
  for x in xs {
    if x > 10 { n = n + 1 }
  }
  n
}
```
