---
code: E0516
name: MarkerBound
title: A marker given as a bound in brackets
spec: 4.2
---

Brackets take forms and named types only. A marker is required of a
type parameter in a `where` clause: `[T: Solid]` is written `[T]` with
`where T is Solid`.

## Rationale

Markers are not earned through functions as forms are, and they can be
required absent, `T is not Secret`, which brackets cannot say. Move the
marker to a `where` clause as the message shows.

## Failing

```crag
fn cache[T: Solid](x: T) -> T { x }
```

## Fixed

```crag
fn cache[T](x: T) -> T where T is Solid { x }
```
