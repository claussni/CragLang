---
code: E0310
name: CannotInfer
title: A type that cannot be inferred
spec: 3.13.2
---

Inference is local: an expression's type comes from its parts and from
the type its place expects. When neither fixes it, as for an empty list
`[]` or an empty map `[:]` bound without an annotation, the type cannot
be inferred.

## Rationale

Nothing is inferred from later uses or across function boundaries, so
the expression must be typed where it is written. Annotate the binding,
as in `let xs: List[Str] = []`, or pass the value where its type is
expected.

## Failing

```crag
fn names() -> List[Str] {
  let xs = []
  xs
}
```

## Fixed

```crag
fn names() -> List[Str] {
  let xs: List[Str] = []
  xs
}
```
