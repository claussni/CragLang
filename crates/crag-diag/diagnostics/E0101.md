---
code: E0101
name: UnknownPath
title: An import names no module or directory
spec: 14.1
---

An import path is resolved from the left: each segment names a
directory or, at the first file, the module. When a segment names
neither a directory nor a module file, the import fails. The path
starts with the package name, so `import demo.geo` reads `geo.crag` of
the package `demo`.

## Rationale

Every path has exactly one reading, so a misspelt segment is not
guessed at. Check the file and directory names against the path, and
start the path with the package name or a package the manifest
imports.

## Failing

```crag
import demo.geometry

fn main() -> Int { area(2) }
// file: geo.crag
pub fn area(side: Int) -> Int { side * side }
```

## Fixed

```crag
import demo.geo

fn main() -> Int { area(2) }
// file: geo.crag
pub fn area(side: Int) -> Int { side * side }
```
