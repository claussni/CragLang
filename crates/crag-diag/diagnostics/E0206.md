---
code: E0206
name: EmbedUnreadable
title: An `embed` whose resource cannot be read
spec: 18.4.1
---

`embed` binds a module-level name to the content of a file of its own
package, read at compile time. The source is a string literal, a path
relative to the module's file. When the file is missing, unreadable or
outside the package, the `embed` is an error.

## Rationale

The resource is part of the module's source, so the build fails rather
than produce a program without it. Check the path and that the file
exists inside the package.

## Failing

```crag
embed greeting: Str from "greeting.txt"

fn main() -> Str { greeting }
```

## Fixed

```crag
embed greeting: Str from "greeting.txt"

fn main() -> Str { greeting }
// file: greeting.txt
Hello
```
