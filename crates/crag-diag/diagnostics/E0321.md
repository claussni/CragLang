---
code: E0321
name: NoErrors
title: An error operation on a value that has no errors
spec: 8.4
---

`check` (`?`) turns a value's errors into `Empty`, and `expect` (`!!`)
turns them into a trap. Both need a value whose type has error members.
Applied to a value without errors, they are refused. `discard` (`~`) is
allowed there.

## Rationale

A `check` or `expect` of a value that cannot fail does nothing and
misleads the reader. Remove the prefix, or apply it to the call that can
fail.

## Failing

```crag
fn port() -> Int {
  let n = 8080
  !! n
}
```

## Fixed

```crag
fn port() -> Int {
  let n = 8080
  n
}
```
