---
code: E0104
name: ModuleRenamed
title: `as` on a module or directory
spec: 14.2
---

`as` renames one imported element. Crag has no module-qualified
references, so a module or a directory has no name of its own in the
importing file, and `import demo.geo as shapes` is an error.

## Rationale

Imported elements enter the namespace directly and are called without
a prefix. Drop the `as`, or rename the single element that collides:
`import demo.geo.area as surface`.

## Failing

```crag
import demo.geo as shapes

fn main() -> Int { area(2) }
// file: geo.crag
pub fn area(side: Int) -> Int { side * side }
```

## Fixed

```crag
import demo.geo.area as surface

fn main() -> Int { surface(2) }
// file: geo.crag
pub fn area(side: Int) -> Int { side * side }
```
