---
code: E0301
name: Mismatch
title: A value of another type than the one expected
spec: 3.13.3
---

A value must have the type its place expects: a parameter's type, a
declared result type, a binding's annotation, a field's type. Types are
structural, so a value fits when its type has the expected shape, and
a union expects one of its members.

## Rationale

Crag infers types inside a body but checks every boundary that states
one. The message names both types, so the fix is to convert the value,
change the annotation, or widen the expected type to a union.

## Failing

```crag
fn label(count: Int) -> Str { count }
```

## Fixed

```crag
fn label(count: Int) -> Str { "{count}" }
```
