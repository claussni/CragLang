---
code: E0657
name: HandlerNotPure
title: A handler with effects where it must be Pure
spec: 11.4
---

A lifecycle kind's form may end with `is Pure`, as those of `Encode`,
`Decode`, `Migrate` and `Embed` do. The handler named in the `on`
clause must then have no effects.

## Rationale

These handlers run at compile time or inside codecs, where I/O is not
allowed. Remove the effect from the handler; a closure handler with an
effect is reported as a type mismatch instead.

## Failing

```crag
import std.io

distinct type Level(n: Int)
  on Embed parseLevel

fn parseLevel(text: Str) -> Level {
  printLine("parsing a level")
  Level(n: 1)
}
```

## Fixed

```crag
distinct type Level(n: Int)
  on Embed parseLevel

fn parseLevel(text: Str) -> Level { Level(n: 1) }
```
