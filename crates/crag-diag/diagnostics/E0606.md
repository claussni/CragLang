---
code: E0606
name: NestedExt
title: An `ext` closure that accesses another `ext`
spec: 9.6
---

An `ext` closure runs while it holds the lock of its `ext`. Accessing
another `ext` inside that closure is an error, as reading a second ref
is in an `update` closure.

## Rationale

Locks that never nest cannot deadlock. Read the other `ext` before the
closure, bind its value with `let`, and use that value inside.

## Failing

```crag
fn copy() -> Int {
  ext source = 1
  ext target = 0
  target.update { t -> source.use() }
  target.use()
}
```

## Fixed

```crag
fn copy() -> Int {
  ext source = 1
  ext target = 0
  let value = source.use()
  target.update { t -> value }
  target.use()
}
```
