---
code: E0003
name: FinalNotFunction
title: `final` on something that is not a function
spec: 3.9
---

`final` marks a function that no overload may outrank. A type or a
form has no overloads, so `final` before `type` or `form` is an error.
The modifiers `pub`, `opaque` and `distinct` remain allowed there.

## Rationale

`final` guards overload resolution, which only functions take part in.
To keep a type from merging with a same-shaped one, use `distinct`; to
hide its fields, use `opaque`.

## Failing

```crag
final type Money(cents: Int)
```

## Fixed

```crag
distinct type Money(cents: Int)
```
