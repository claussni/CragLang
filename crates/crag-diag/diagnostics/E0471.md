---
code: E0471
name: RecursiveSuccess
title: A recursive function without its success type
spec: 3.13.1
---

A function may leave its return type to inference, but inferring it
must not depend on itself. This error reports a call of a function
whose success type could not be inferred because the inference runs in
a circle that is not a plain call cycle, such as one through a
module-level value. Call cycles between functions are E0472.

## Rationale

Inference is local, so a cycle has to be cut by a written type. When
the cycle runs through a module-level value, the value depends on
itself too (E0473), and the cure is to break that cycle: give the value
a value that does not call back into the function.

## Failing

```crag
let base = start()
fn start() { base + 1 }
```

## Fixed

```crag
let base = 100
fn start() { base + 1 }
```
