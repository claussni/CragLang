---
code: E0455
name: PassOutsideCase
title: pass outside the body of a case arm
spec: 8.2
---

`pass` hands the alternatives a `case` has not handled to the caller.
It stands only as a whole arm of a `case`, or as the body of an arm.
Anywhere else, including inside a block of an arm, it is refused.

## Rationale

`pass` makes propagation visible at the one place a result is
inspected, so it belongs to the `case` itself. Write `pass` as its own
arm, or name the value and return it.

## Failing

```crag
type NotFound(..Error)
fn find(id: Int) -> Int | NotFound { if id > 0 { id } else { NotFound } }
fn twice(id: Int) -> Int | NotFound {
  case find(id) {
    n: Int -> n * 2
    _ -> { pass }
  }
}
```

## Fixed

```crag
type NotFound(..Error)
fn find(id: Int) -> Int | NotFound { if id > 0 { id } else { NotFound } }
fn twice(id: Int) -> Int | NotFound {
  case find(id) {
    n: Int -> n * 2
    pass
  }
}
```
