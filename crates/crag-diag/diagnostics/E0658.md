---
code: E0658
name: SignalNotSolid
title: A signal type that is not Solid
spec: 11.1
---

Every signal type must be Solid. Its fields may hold only Solid
values: no function that is not `is Pure`, no `Lazy`, ref or open
record. The message names the field that breaks it.

## Rationale

A signal travels up the scope tree, even across tasks, and is handled
later, so it must never fail or act when it is read. Carry plain data
in the signal, or mark a function field `is Pure`.

## Failing

```crag
type JobDone(..Signal, id: Int, retry: () -> Int)
```

## Fixed

```crag
type JobDone(..Signal, id: Int, attempts: Int)
```
