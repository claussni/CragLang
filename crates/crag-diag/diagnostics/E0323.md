---
code: E0323
name: MustLeave
title: The `else` of a `let … else` that does not leave
spec: 7.1.1
---

A `let` with `else` binds only when the value matches its pattern;
otherwise the `else` part runs. That part must leave, by `return`, a
trap, or a call that returns `Never`. An `else` part that can complete
normally is refused.

## Rationale

If the `else` part could finish, the code after the `let` would run
with the binding unbound. End the `else` part with `return`, or use
`case` to give a value in each case.

## Failing

```crag
fn first(xs: List[Int]) -> Int {
  let [x, ..] = xs else { 0 }
  x
}
```

## Fixed

```crag
fn first(xs: List[Int]) -> Int {
  let [x, ..] = xs else { return 0 }
  x
}
```
