---
code: E0802
name: EmbedHandler
title: An `embed` of a type without an `on Embed` handler
spec: 18.4.1
---

An `embed` of `Bytes` or `Str` takes the resource as it is. Any other
annotated type must declare an `on Embed` handler, a Pure function that
turns the resource's `Bytes` or `Str` into a value of the type.

## Rationale

The compiler has no built-in way to parse a resource into a domain
type. Declare `on Embed` with a parsing function on the type, or embed
a `Str` and convert it with a module-level `let`.

## Failing

```crag
distinct type Level(n: Int)

embed level: Level from "level.txt"
// file: level.txt
high
```

## Fixed

```crag
distinct type Level(n: Int)
  on Embed parseLevel

fn parseLevel(text: Str) -> Level | EmbedError {
  case text.trim() {
    "low" -> Level(n: 1)
    "high" -> Level(n: 3)
    _ -> EmbedError(message: "expected low or high", line: 1, column: 1)
  }
}

embed level: Level from "level.txt"
// file: level.txt
high
```
