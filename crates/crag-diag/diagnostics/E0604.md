---
code: E0604
name: EscapingVar
title: An escaping closure that captures a `var`
spec: 6.4.1
---

A closure may read a captured `var`, but a closure that escapes must
not capture one. A closure escapes when it is returned, stored or
otherwise outlives the block that binds the `var`. The compiler infers
whether a closure escapes.

## Rationale

A `var` may change after the closure is made, so an escaping closure
would see a value that depends on when it runs. Compute the final value
first and bind it with `let`, then capture that.

## Failing

```crag
fn greeter(name: Str) -> () -> Str {
  var greeting = "Hello"
  if name == "" { greeting = "Hi" }
  { -> "{greeting}, {name}" }
}
```

## Fixed

```crag
fn greeter(name: Str) -> () -> Str {
  let greeting = if name == "" { "Hi" } else { "Hello" }
  { -> "{greeting}, {name}" }
}
```
