---
code: E0505
name: NotDerived
title: A type that does not fit a derived form by its structure
spec: 19.11
---

Records and unions fit `Eq`, `Hash`, `Show` and `Ordered` by their
structure, through the prelude's generic `equals`, `hash`, `show` and
`compare`. A type does not fit when one of its parts does not: a field
of a function type fits none of the four, and a type that is `not F`
never fits `F`. Using the derived function for such a type is refused.

## Rationale

A function value has no structure to compare, hash or print, so a
record that holds one cannot derive the forms. Declare the type's own
function, which a call prefers to the derived one, and call it.

## Failing

```crag
type Job(name: Str, run: () -> Int)
fn names(jobs: List[Job]) -> List[Str] { jobs.map(show) }
```

## Fixed

```crag
type Job(name: Str, run: () -> Int)
fn show(j: Job) -> Str { "Job({j.name})" }
fn names(jobs: List[Job]) -> List[Str] { jobs.map({ j -> show(j) }) }
```
