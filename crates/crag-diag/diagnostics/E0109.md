---
code: E0109
name: ImportCycle
title: Modules that import each other
spec: 14.1
---

Import cycles are not allowed: no module may import itself, directly
or through other modules. The message lists the modules of the cycle
in import order.

## Rationale

Without cycles, modules have an order in which each one can be checked
and initialized after those it uses. Move the shared declarations into
a module of their own that both import, or let one module stop
importing the other.

## Failing

```crag
import demo.a

fn main() -> Int { one() }
// file: a.crag
import demo.b

pub fn one() -> Int { 1 }
// file: b.crag
import demo.a

pub fn two() -> Int { one() + 1 }
```

## Fixed

```crag
import demo.a

fn main() -> Int { one() }
// file: a.crag
pub fn one() -> Int { 1 }
// file: b.crag
import demo.a

pub fn two() -> Int { one() + 1 }
```
