---
code: E0320
name: NeverEmpty
title: `?.` on a value that cannot be `Empty`
spec: 6.8
---

`a?.b` gives `Empty` when `a` is `Empty` and the access otherwise. When
the type of `a` has no `Empty` member, the `?.` would never stop, and it
is refused.

## Rationale

A needless `?.` hides that the value is always present and makes the
result an `Option` for no reason. Write `.` instead.

## Failing

```crag
type User(name: Str)
fn label(u: User) -> Str { u?.name }
```

## Fixed

```crag
type User(name: Str)
fn label(u: User) -> Str { u.name }
```
