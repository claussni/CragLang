---
code: E0503
name: FormAmbiguous
title: A form whose function several functions provide equally well
spec: 5.6.1
---

A form's function is filled like a call: of the visible functions that
take the type, the most specific one is chosen. When several fit and
none is more specific than the others, the bound is ambiguous. The
message names the form, the function and its type.

## Rationale

Dispatch is static, so every ambiguity is an error where it is created,
never a guess. Add an overload that is more specific than all of them,
such as one that takes exactly the type, or import only one of the
rival functions.

## Failing

```crag
form Weighed[T] {
  weight(x: T) -> Int
}
type Crate(kg: Int)
type Sack(kg: Int)
type Barrel(kg: Int)
fn weight(x: Crate | Sack) -> Int { 1 }
fn weight(x: Crate | Barrel) -> Int { 2 }
fn heavy[T: Weighed](x: T) -> Bool { weight(x) > 30 }
fn main() -> Bool { heavy(Crate(kg: 40)) }
```

## Fixed

```crag
form Weighed[T] {
  weight(x: T) -> Int
}
type Crate(kg: Int)
type Sack(kg: Int)
type Barrel(kg: Int)
fn weight(x: Crate | Sack) -> Int { 1 }
fn weight(x: Crate | Barrel) -> Int { 2 }
fn weight(x: Crate) -> Int { x.kg }
fn heavy[T: Weighed](x: T) -> Bool { weight(x) > 30 }
fn main() -> Bool { heavy(Crate(kg: 40)) }
```
