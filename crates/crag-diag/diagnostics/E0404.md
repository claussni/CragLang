---
code: E0404
name: DuplicateField
title: A field given or declared twice
spec: 6.7
---

Each field appears once: in a type's declaration, in a record
construction and in a field-update list. A dotted path such as `pos.x`
counts as a change of `pos`, so it cannot follow a value for the whole
`pos` in the same list.

## Rationale

Two values for one field leave it unclear which one wins. Keep one of
them, or fold the changes into one value for the field.

## Failing

```crag
type Point(x: Int, y: Int)
fn origin() -> Point { Point(x: 0, x: 1, y: 0) }
```

## Fixed

```crag
type Point(x: Int, y: Int)
fn origin() -> Point { Point(x: 0, y: 0) }
```
