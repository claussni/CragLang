---
code: E0513
name: MissingCombined
title: Overloads with incomparable bounds and no combined overload
spec: 5.6.1
---

Within one module, two overloads with the same parameters and
incomparable bounds, such as `[T: Named]` and `[T: Sized]`, must come
with their combined overload. Without it, a type that fits both forms
would have no most specific candidate. The message gives the signature
to add.

## Rationale

Ambiguity is fixed where it is created, so a call never meets one inside
a module's overload set. Add the overload the message suggests, which
requires both bounds and wins for types that fit both.

## Failing

```crag
form Named[T] {
  name(x: T) -> Str
}
form Sized[T] {
  size(x: T) -> Int
}
fn describe[T: Named](x: T) -> Str { name(x) }
fn describe[T: Sized](x: T) -> Str { "{size(x)} bytes" }
```

## Fixed

```crag
form Named[T] {
  name(x: T) -> Str
}
form Sized[T] {
  size(x: T) -> Int
}
fn describe[T: Named](x: T) -> Str { name(x) }
fn describe[T: Sized](x: T) -> Str { "{size(x)} bytes" }
fn describe[T](x: T) -> Str where Named[T], Sized[T] { "{name(x)}, {size(x)} bytes" }
```
