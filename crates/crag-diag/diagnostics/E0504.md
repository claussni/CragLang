---
code: E0504
name: NoneOfForms
title: No form of a union of forms holds
spec: 4.7
---

A union of forms, `[K: A | B]`, holds when the type argument fits at
least one member. When it fits none of them, the bound fails, and the
message lists the forms with the argument filled in.

## Rationale

A union of forms lets one function take types that support either of
several operations. Give the type the functions of one of the forms, or
pass a type that already fits one.

## Failing

```crag
form Weighed[T] {
  weight(x: T) -> Int
}
form Counted[T] {
  count(x: T) -> Int
}
type Crate(kg: Int)
fn heavy[T: Weighed | Counted](x: T) -> Bool { True }
fn main() -> Bool { heavy(Crate(kg: 40)) }
```

## Fixed

```crag
form Weighed[T] {
  weight(x: T) -> Int
}
form Counted[T] {
  count(x: T) -> Int
}
type Crate(kg: Int)
fn weight(c: Crate) -> Int { c.kg }
fn heavy[T: Weighed | Counted](x: T) -> Bool { True }
fn main() -> Bool { heavy(Crate(kg: 40)) }
```
