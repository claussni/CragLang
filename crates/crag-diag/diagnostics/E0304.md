---
code: E0304
name: NoLift
title: Union lifting finds no function for a member
spec: 4.6.1
---

A call with a union argument dispatches on the value's member, so a
function of the name must take each member of the union. When one
member has no function, the call is refused, and the message names the
members that lack one.

## Rationale

The compiler writes the `case` over the members for you, and a member
without a function would leave a hole in it. Add the missing overload,
or narrow the value with `case` before the call.

## Failing

```crag
type Circle(radius: Float)
type Square(side: Float)
type Line(length: Float)

fn area(c: Circle) -> Float { 3.14 * c.radius * c.radius }
fn area(s: Square) -> Float { s.side * s.side }

fn total(shape: Circle | Line) -> Float { area(shape) }
```

## Fixed

```crag
type Circle(radius: Float)
type Square(side: Float)
type Line(length: Float)

fn area(c: Circle) -> Float { 3.14 * c.radius * c.radius }
fn area(s: Square) -> Float { s.side * s.side }
fn area(l: Line) -> Float { 0.0 }

fn total(shape: Circle | Line) -> Float { area(shape) }
```
