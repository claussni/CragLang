---
code: E0451
name: NeverMatches
title: A pattern that cannot match the value's type
spec: 7.2
---

A type pattern, in a `case` arm, in `x is T` or in a `let … else`,
tests for one of the types the value can have. When no member of the
value's type fits the pattern's type, the test can never succeed and is
refused.

## Rationale

A test that never matches is a mistake: a wrong type in the pattern, or
a value of another type than intended. Test for a member of the value's
type, or fix the value's type.

## Failing

```crag
type NotFound
fn label(r: Int | NotFound) -> Str {
  case r {
    s: Str -> s
    _ -> "missing"
  }
}
```

## Fixed

```crag
type NotFound
fn label(r: Int | NotFound) -> Str {
  case r {
    n: Int -> "{n}"
    _ -> "missing"
  }
}
```
