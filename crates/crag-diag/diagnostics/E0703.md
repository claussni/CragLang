---
code: E0703
name: NotTransportable
title: Code sent as an `Expr` that holds a form that cannot travel
spec: 18.6
---

A closure literal that becomes an `Expr` may not contain a `ref` or
`ext` binding, an `atomic` block, an `embed`, an `on` handler or `???`.
The message names the form it found.

## Rationale

These forms need state, resources or source files of the sending
program, or can only trap, so a receiver could not run them. Compute
the value with plain expressions and `let` bindings inside the closure.

## Failing

```crag
import std.transport

fn send(job: Expr[((Int) -> Int is Pure)]) -> Int { job(1) }

fn total() -> Int {
  send({ n -> ??? })
}
```

## Fixed

```crag
import std.transport

fn send(job: Expr[((Int) -> Int is Pure)]) -> Int { job(1) }

fn total() -> Int {
  send({ n -> n * 2 })
}
```
