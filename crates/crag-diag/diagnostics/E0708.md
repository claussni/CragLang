---
code: E0708
name: PrivateTypeSent
title: Code sent as an `Expr` that names a type that is not `pub`
spec: 18.6
---

The tree of a closure sent as an `Expr` may name a `distinct` or
`opaque` type only when it is `pub`. This holds for the closure's body,
its captures, and the helpers it bundles. Structural types are spelled
out in the tree and need no `pub`.

## Rationale

A receiver resolves a nominal type by its declaring module and cannot
see private names. Mark the type `pub`, or keep it out of the code you
send.

## Failing

```crag
import std.transport

distinct type Meters(raw: Int)

fn send(job: Expr[((Int) -> Int is Pure)]) -> Int { job(1) }

fn run() -> Int {
  send({ n -> Meters(raw: n * 1000).raw })
}
```

## Fixed

```crag
import std.transport

pub distinct type Meters(raw: Int)

fn send(job: Expr[((Int) -> Int is Pure)]) -> Int { job(1) }

fn run() -> Int {
  send({ n -> Meters(raw: n * 1000).raw })
}
```
