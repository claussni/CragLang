---
code: E0108
name: NameCollision
title: A name that comes from more than one place
spec: 14.3
---

When imports meet, functions with different signatures merge into one
overload set and identical types merge silently. The same name with an
identical signature from two modules, or any other mix that cannot
merge, is a collision. A file may not reuse a prelude name either,
unless it renames the prelude's element.

## Rationale

A silent choice between two equal functions would make a call depend
on import order. Rename one at the import with `as`, or import only
the elements you need.

## Failing

```crag
import demo.square
import demo.circle

fn main() -> Int { area(2) }
// file: square.crag
pub fn area(side: Int) -> Int { side * side }
// file: circle.crag
pub fn area(radius: Int) -> Int { 3 * radius * radius }
```

## Fixed

```crag
import demo.square
import demo.circle.area as circleArea

fn main() -> Int { area(2) + circleArea(1) }
// file: square.crag
pub fn area(side: Int) -> Int { side * side }
// file: circle.crag
pub fn area(radius: Int) -> Int { 3 * radius * radius }
```
