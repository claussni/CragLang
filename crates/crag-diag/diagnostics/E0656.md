---
code: E0656
name: ClosureDoesNotFit
title: A handler closure that does not fit its form
spec: 11.4
---

A closure written as a handler in an `on` clause must fit exactly one
member of its kind's form. The written parameter types pick the
member; a closure that fits none of them, or several, is an error. The
message shows the form.

## Rationale

The runtime must know which shape of handler it calls. Write the
closure's parameter types so they match one member of the form in the
message.

## Failing

```crag
distinct type Level(n: Int)
  on Embed { n: Int -> Level(n: n) }
```

## Fixed

```crag
distinct type Level(n: Int)
  on Embed { text: Str -> Level(n: 1) }
```
