---
code: E0202
name: NotAType
title: A name where a type is expected that names no type
spec: 3.13.1
---

A parameter's type, a result type, an annotation or a type argument
must name a type in scope: a declared, imported or prelude type, an
alias, or a type parameter. A name that is undefined there, or that
names a value or function, is an error.

## Rationale

Written types are the boundaries that inference checks against, so
they must resolve exactly. Check the spelling, declare or import the
type, or use an alias such as `type Count = Int`.

## Failing

```crag
fn area(side: Count) -> Int { side * side }
```

## Fixed

```crag
type Count = Int

fn area(side: Count) -> Int { side * side }
```
