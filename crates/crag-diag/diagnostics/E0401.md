---
code: E0401
name: NoField
title: A field the type does not have
spec: 3.3
---

`v.name` reads a field of `v`, and the type of `v` must have a field
of that name. A record has the fields it declares and those it spreads
from a parent. When no field and no function of the name fits, the
access is refused and the message names the type.

## Rationale

Field names are checked at compile time, so a misspelt or missing field
never reaches run time. Check the spelling against the type's
declaration, or call a function instead: `xs.count()` is a call, not a
field.

## Failing

```crag
type Point(x: Int, y: Int)
fn sum(p: Point) -> Int { p.x + p.z }
```

## Fixed

```crag
type Point(x: Int, y: Int)
fn sum(p: Point) -> Int { p.x + p.y }
```
