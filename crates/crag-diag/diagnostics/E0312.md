---
code: E0312
name: TypeArgCount
title: The wrong number of type arguments
spec: 4.2
---

A generic type or function takes as many type arguments as it declares
type parameters. Writing a generic type without its arguments, such as
`Pair` for `type Pair[T](...)`, or with too many, is refused.

## Rationale

A generic type alone is not a complete type, since its fields depend
on the arguments. Write one type argument for each parameter, as in
`Pair[Int]`.

## Failing

```crag
type Pair[T](left: T, right: T)
fn sum(p: Pair) -> Int { p.left + p.right }
```

## Fixed

```crag
type Pair[T](left: T, right: T)
fn sum(p: Pair[Int]) -> Int { p.left + p.right }
```
