---
code: E0102
name: PathPastElement
title: An import path goes on past an element
spec: 14.1
---

The segment after a module names one of its elements, and the path
ends there. An element has no members of its own to import, so a
selection `{…}` or further segments after it are an error.

## Rationale

Only modules and directories contain things that can be imported.
Import the element itself, or put the selection directly after the
module: `import demo.geo.{area, perimeter}`.

## Failing

```crag
import demo.geo.area.{square}

fn main() -> Int { square(2) }
// file: geo.crag
pub fn square(side: Int) -> Int { side * side }
pub fn area(width: Int, height: Int) -> Int { width * height }
```

## Fixed

```crag
import demo.geo.{square}

fn main() -> Int { square(2) }
// file: geo.crag
pub fn square(side: Int) -> Int { side * side }
pub fn area(width: Int, height: Int) -> Int { width * height }
```
