---
code: E0453
name: NotExhaustive
title: A case that misses some values
spec: 7.2
---

A `case` must cover every value of its subject's type. The compiler
checks the arms against the type's members, literals, ranges and
record shapes, and names a value no arm matches. `pass` covers the
error members that are left.

## Rationale

An exhaustive `case` means no value falls through at run time, and a
new member of a union is reported at every `case` that misses it. Add
an arm for the missing value, a `_` arm, or `pass` for errors.

## Failing

```crag
type Circle(r: Float)
type Square(side: Float)
fn area(s: Circle | Square) -> Float {
  case s {
    c: Circle -> 3.14 * c.r * c.r
  }
}
```

## Fixed

```crag
type Circle(r: Float)
type Square(side: Float)
fn area(s: Circle | Square) -> Float {
  case s {
    c: Circle -> 3.14 * c.r * c.r
    q: Square -> q.side * q.side
  }
}
```
