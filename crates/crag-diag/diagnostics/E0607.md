---
code: E0607
name: NotSolid
title: A type that must be Solid and is not
spec: 3.11
---

A type marked `is Solid`, or passed where a type parameter requires
`T is Solid`, must be Solid. A type is Solid when its fields are, its
`where` conditions are Pure and it has no `on Dispose` handler. A
function that is not `is Pure`, `Lazy`, a ref and an open record are
never Solid. The message names the field that breaks it.

## Rationale

Solid values can never produce a runtime error, which is what makes
them safe to share and keep. Mark a function field `is Pure`, change
the field's type, or drop the `is Solid` claim.

## Failing

```crag
type Rule(name: Str, accepts: (Int) -> Bool) is Solid
```

## Fixed

```crag
type Rule(name: Str, accepts: ((Int) -> Bool is Pure)) is Solid
```
