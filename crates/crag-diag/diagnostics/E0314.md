---
code: E0314
name: NotAValue
title: A name used as a value that is not one
spec: 3.3
---

A tag type or a record type without fields has exactly one value,
written by its name. A record type with fields is not a value by its
name alone: it is built with its fields, as in `Point(x: 1, y: 2)`. A
form is never a value.

## Rationale

Only a type with a single value can stand for that value. Construct
the record with its fields, or use a value of the type.

## Failing

```crag
type Point(x: Int, y: Int)
fn origin() -> Point {
  let p = Point
  p
}
```

## Fixed

```crag
type Point(x: Int, y: Int)
fn origin() -> Point {
  let p = Point(x: 0, y: 0)
  p
}
```
