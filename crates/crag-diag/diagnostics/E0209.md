---
code: E0209
name: NotAVar
title: An assignment to a binding that is not a `var`
spec: 5.2
---

`var` is the only binding that can be rebound. Assigning to a `let`, a
parameter or a pattern binding is an error.

## Rationale

Bindings are immutable unless declared otherwise, so a reader can
trust a `let` to keep its value. Declare the binding with `var`, or
bind the new value to a new name.

## Failing

```crag
fn countdown(start: Int) -> Int {
  let n = start
  n = n - 1
  n
}
```

## Fixed

```crag
fn countdown(start: Int) -> Int {
  var n = start
  n = n - 1
  n
}
```
