---
code: E0106
name: PrivateElement
title: An import names an element that is not `pub`
spec: 14.1
---

Everything in a module is private by default; only declarations marked
`pub` are exported. Importing a private element by name is an error.
A whole-module import simply leaves private elements out.

## Rationale

Privacy lets a module change its helpers without breaking importers.
Mark the declaration `pub` if other modules should use it, or use a
public function that the module exports instead.

## Failing

```crag
import demo.geo.area

fn main() -> Int { area(2) }
// file: geo.crag
fn area(side: Int) -> Int { side * side }
```

## Fixed

```crag
import demo.geo.area

fn main() -> Int { area(2) }
// file: geo.crag
pub fn area(side: Int) -> Int { side * side }
```
