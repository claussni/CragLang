---
code: E0317
name: NotIterable
title: Iterating a value that cannot be iterated
spec: 7.3
---

`for x in e` iterates a collection: a list, a set, a map, a grid, a
range or a stream source. Iterating a value of any other type, such as a number, is
refused, and the message names its type.

## Rationale

A number is not a sequence of values. To count, iterate a range such
as `1..n`; to iterate a record's parts, iterate the collection field.

## Failing

```crag
fn total(n: Int) -> Int {
  var t = 0
  for x in n { t = t + x }
  t
}
```

## Fixed

```crag
fn total(n: Int) -> Int {
  var t = 0
  for x in 1..n { t = t + x }
  t
}
```
