---
code: E0512
name: FitsBanned
title: A function that would make a type fit a form it forbids
spec: 3.11
---

A declared type can forbid a form with `is not F`. It then never fits
`F`, and declaring a function that would make it fit is an error in any
module. The ban also switches off a derived form such as `Show`.

## Rationale

A ban protects values that must not be printed, hashed or compared, such
as a password. Give the function another name so it does not fill the
form, or remove the ban if the type should fit after all.

## Failing

```crag
type Password(raw: Str) is not Show
fn show(p: Password) -> Str { "***" }
```

## Fixed

```crag
type Password(raw: Str) is not Show
fn redacted(p: Password) -> Str { "***" }
```
