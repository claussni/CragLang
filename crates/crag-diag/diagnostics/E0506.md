---
code: E0506
name: ParamNotSolid
title: A type argument that is not Solid where required
spec: 4.2
---

`where T is Solid` requires every type argument for `T` to be `Solid`:
its values can never produce a runtime error (§3.11). A type is not
Solid when it holds a function that is not `Pure`, a `Lazy`, a ref, an
open record, or is marked `not Solid`. The message says which part of
the type breaks it.

## Rationale

Code that must not fail, such as a cache or a value sent to another
task, relies on the requirement. Remove or replace the part the message
names, for example a closure field by a plain value, or drop the
requirement if the function does not need it.

## Failing

```crag
type Retry(limit: Int, delay: () -> Int)
fn keep[T](x: T) -> T where T is Solid { x }
fn main() -> Retry { keep(Retry(limit: 3, delay: { -> 100 })) }
```

## Fixed

```crag
type Retry(limit: Int, delay: Int)
fn keep[T](x: T) -> T where T is Solid { x }
fn main() -> Retry { keep(Retry(limit: 3, delay: 100)) }
```
