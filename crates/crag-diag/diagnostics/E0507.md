---
code: E0507
name: MarkerNotMet
title: A type argument that does not meet a marker requirement
spec: 4.2
---

A `where` clause can require a type parameter to carry a marker or to
lack it: `T is Secret`, `T is not Secret`. Whether a type argument
carries a marker is decided from its type alone. Inside generic code, a
type parameter carries only what its own requirements say, so a marker
they do not mention is not known and the requirement is not met.

## Rationale

Markers such as `Secret` and `Pure` guard what a function may do with a
value. Pass a type that meets the requirement, or, in generic code,
state the same requirement on the caller's own type parameter.

## Failing

```crag
type ApiKey(raw: Str) is Secret
fn log[T](x: T) -> Str where T is not Secret { "{x}" }
fn main() -> Str { log(ApiKey(raw: "k-123")) }
```

## Fixed

```crag
type ApiKey(raw: Str) is Secret
type KeyId(n: Int)
fn log[T](x: T) -> Str where T is not Secret { "{x}" }
fn main() -> Str { log(KeyId(n: 7)) }
```
