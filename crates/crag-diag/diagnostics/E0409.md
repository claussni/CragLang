---
code: E0409
name: Overlap
title: Union members that overlap
spec: 3.6.1
---

A value belongs to exactly one member of a union, so the members of a
union written in source must not overlap. Two members overlap when one
spreads the other, as `NotFound` spreads `LookupError`. A generic union
instantiated so that members overlap is refused the same way.

## Rationale

With overlapping members a value would belong to two of them, and
matching on the union would be ambiguous. Drop the member the other
already contains: `LookupError` alone holds every `NotFound`, which
stays matchable.

## Failing

```crag
type LookupError(..Error)
type NotFound(..LookupError)
fn find(id: Int) -> Int | NotFound | LookupError {
  if id > 0 { id } else { NotFound }
}
```

## Fixed

```crag
type LookupError(..Error)
type NotFound(..LookupError)
fn find(id: Int) -> Int | LookupError {
  if id > 0 { id } else { NotFound }
}
```
