---
code: E0801
name: NotUtf8
title: An `embed` of text from a resource that is not UTF-8
spec: 18.4.1
---

An `embed` of `Str`, or of a type whose `on Embed` handler takes a
`Str`, needs a resource of valid UTF-8. The message gives the byte at
which the resource stops being UTF-8.

## Rationale

`Str` is UTF-8 text, and the compiler does not guess an encoding.
Convert the file to UTF-8, or embed it as `Bytes`, the default, and
decode it yourself.

## Failing

```crag
embed logo: Str from "logo.png"
// file: logo.png hex
89 50 4e 47 0d 0a 1a 0a
```

## Fixed

```crag
embed logo from "logo.png"
// file: logo.png hex
89 50 4e 47 0d 0a 1a 0a
```
