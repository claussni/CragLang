---
code: E0105
name: UnknownElement
title: An import names an element the module does not have
spec: 14.2
---

An import of `module.name`, or a selection `module.{a, b}`, names
elements the module declares. When the module has no element of a
name, the import fails.

## Rationale

A selective import states exactly which names a file uses, so a
missing one is reported where it is imported. Check the spelling, or
look up the module's elements with `members`.

## Failing

```crag
import demo.geo.volume

fn main() -> Int { area(2) }
// file: geo.crag
pub fn area(side: Int) -> Int { side * side }
```

## Fixed

```crag
import demo.geo.area

fn main() -> Int { area(2) }
// file: geo.crag
pub fn area(side: Int) -> Int { side * side }
```
