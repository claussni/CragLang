---
code: E0509
name: MixedBound
title: A bound that unites forms with types
spec: 4.7
---

A bound may be a union of forms, which holds when one of them does, or
a union of types. It cannot mix the two: `[T: Sized | Int]` is refused.

## Rationale

A union of forms and a union of types mean different things: fitting
at least one form against holding a value of exactly one member. To
admit `Int` beside a form, give `Int` the form's functions and bound by
the form alone.

## Failing

```crag
form Sized[T] {
  size(x: T) -> Int
}
fn total[T: Sized | Int](xs: List[T]) -> Int { 0 }
```

## Fixed

```crag
form Sized[T] {
  size(x: T) -> Int
}
fn size(n: Int) -> Int { n }
fn total[T: Sized](xs: List[T]) -> Int { 0 }
```
