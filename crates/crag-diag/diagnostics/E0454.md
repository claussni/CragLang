---
code: E0454
name: Refutable
title: A pattern that can fail where it must match
spec: 7.1.1
---

The pattern of a `let` without `else`, and the pattern of a `for`, must
match every value of its type. A pattern that can fail, such as a
literal in a field or a list of fixed length, is refused, and the
message names a value it misses.

## Rationale

A binding that cannot fail never leaves a name unbound. Use
`let … else` with an `else` that leaves, or a `case` with an arm for
the other values.

## Failing

```crag
fn first(xs: List[Int]) -> Int {
  let [x] = xs
  x
}
```

## Fixed

```crag
fn first(xs: List[Int]) -> Int {
  let [x] = xs else { return 0 }
  x
}
```
