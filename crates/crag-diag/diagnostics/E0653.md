---
code: E0653
name: SecondHandler
title: A second handler of the same kind
spec: 11.4
---

A type declares at most one handler of each lifecycle kind. This holds
also where the kind's form is a union and accepts either of two
handler shapes, as `Embed` does.

## Rationale

With two handlers the runtime could not tell which one to call. Keep
one `on` clause per kind and delete the other.

## Failing

```crag
distinct type Level(n: Int)
  on Embed fromText
  on Embed fromBytes

fn fromText(text: Str) -> Level { Level(n: 1) }
fn fromBytes(bytes: Bytes) -> Level { Level(n: 2) }
```

## Fixed

```crag
distinct type Level(n: Int)
  on Embed fromText

fn fromText(text: Str) -> Level { Level(n: 1) }
```
