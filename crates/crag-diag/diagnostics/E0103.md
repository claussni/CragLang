---
code: E0103
name: HiddenPath
title: An import path the package does not expose
spec: 14.5
---

A module may import the modules of its own package, `std`, and the
exported modules of the packages its manifest imports. Another
package's module is hidden when that package does not `export` it,
when the manifest does not import the package, or when it is a
development import and the importer is not a test or tool module.

## Rationale

A package is a visibility boundary: what it does not export may change
without a new major version. The message says which rule applies; add
the `import` to the manifest, use an exported module, or ask the
package to export the one you need.

## Failing

```crag
import geo.solid

fn main() -> Int { volume(2) }
// file: package.crag
package demo 0.1
runtime 0.0

import geo 1.0 from "path:.vendor/geo"
// file: sbom.crag
package geo 1.0 path ".vendor/geo"
// file: .vendor/geo/package.crag
package geo 1.0
runtime 0.0

export geo.shape
// file: .vendor/geo/shape.crag
pub fn area(side: Int) -> Int { side * side }
// file: .vendor/geo/solid.crag
pub fn volume(side: Int) -> Int { side * side * side }
```

## Fixed

```crag
import geo.solid

fn main() -> Int { volume(2) }
// file: package.crag
package demo 0.1
runtime 0.0

import geo 1.0 from "path:.vendor/geo"
// file: sbom.crag
package geo 1.0 path ".vendor/geo"
// file: .vendor/geo/package.crag
package geo 1.0
runtime 0.0

export geo.{shape, solid}
// file: .vendor/geo/shape.crag
pub fn area(side: Int) -> Int { side * side }
// file: .vendor/geo/solid.crag
pub fn volume(side: Int) -> Int { side * side * side }
```
