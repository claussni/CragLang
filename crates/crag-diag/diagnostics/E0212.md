---
code: E0212
name: ExpectedType
title: An expression where a type is expected
spec: 7.1
---

A type position takes a type: after `:` in a parameter or binding,
after `->`, in type arguments and after `is` in a type test. An
expression there, such as a literal or a call, is an error. A value
test `x is T` takes a type, not an `is` clause such as `not Str`,
since markers are required of type parameters and never tested on
values.

## Rationale

Types are written, not computed. Write the type itself; to test that a
value is not of a type, negate the test: `not (x is Str)`.

## Failing

```crag
fn isNumber(x: Int | Str) -> Bool { x is not Str }
```

## Fixed

```crag
fn isNumber(x: Int | Str) -> Bool { not (x is Str) }
```
